# SME Books (installable app)
Host these files together over HTTPS, e.g. GitHub Pages:
1. Create a repo, upload index.html, manifest.json, sw.js, icon-192.png, icon-512.png.
2. Settings > Pages > deploy from the main branch.
3. Open the page on the phone. Android Chrome: menu > Install app. iPhone Safari: Share > Add to Home Screen.
After editing index.html, phones now fetch the newest files whenever they are online.
Data is stored on the device only. Use Settings > Backup before clearing browser data or changing phones.
